Casos de Estudio & Blogs

Caso 1: Creación, Gestión de Usuarios y Respaldo en MySQL (Servidores II)

a. Descripción:

Implementación y administración integral de un sistema de bases de datos sobre una máquina virtual con Ubuntu Server, abarcando desde la definición de modelos hasta políticas de privilegios y recuperación ante desastres.

b. Requerimientos del cliente / proyecto:

  • Crear una base de datos funcional para gestión de inventario.
  • Restringir el acceso de los usuarios según su rol (un usuario de consulta y un usuario administrador).
  • Garantizar un plan de respaldo (`mysqldump`) y un protocolo de restauración probado ante posibles fallos.

c. ¿Cómo se diseñó la solución?:

Se definió una arquitectura de seguridad por roles en MySQL asignando el privilegio `SELECT` exclusivo al usuario `consultor` y `ALL PRIVILEGES` al usuario `administrador_inv`. Adicionalmente, se planificó la exportación periódica en scripts SQL para permitir clonación y restauración rápida.

d. ¿Cómo se implementó la solución?:

A través de la consola en Ubuntu Server se ejecutó la definición de tablas (`CREATE TABLE productos`), inserción de datos iniciales y la asignación de permisos mediante `GRANT`. Se generó el respaldo ejecutable con `mysqldump` y se probó la restauración creando una base de datos secundaria `inventario_restaurada`.

e. ¿Cuál fue el resultado?:

Acceso restringido validado correctamente (el usuario consultor obtuvo un error de permisos al intentar hacer `INSERT`), y comprobación del 100% de la integridad de los datos restaurados desde el archivo de respaldo.

Caso 2: Análisis de Conectividad a Internet y Productividad Académica

a. Descripción:

Proyecto de investigación y análisis de datos orientado a evaluar el impacto de las métricas de red en el rendimiento escolar de estudiantes de ingeniería.

b. Requerimientos del cliente / proyecto:

  • Identificar la relación entre variables cuantitativas (Mbps, horas de uso) y cualitativas (satisfacción, estabilidad).
  • Diseñar una base de datos para la ingesta y estructuración de la información recolectada mediante encuestas digitales.

c. ¿Cómo se diseñó la solución?:

Se estructuró una base de datos relacional para procesar encuestas de Google Forms y exportarlas a herramientas de análisis como Excel y librerías de Python para cálculos estadísticos descriptivos.

d. ¿Cómo se implementó la solución?:

Se llevó a cabo un muestreo probabilístico aleatorio simple, se limpió el conjunto de datos y se aplicaron modelos de correlación para evaluar el rendimiento escolar frente al tiempo de pérdida por fallas de conexión.

e. ¿Cuál fue el resultado?:

Se generó un informe técnico detallado que identificó los principales cuellos de botella de conectividad y ofreció conclusiones claras sobre la infraestructura necesaria para sostener la productividad académica en la nube.
