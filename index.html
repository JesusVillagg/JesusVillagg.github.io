Casos de Estudio & Blogs

Caso 1: Análisis de Conectividad a Internet y Productividad Académica

a. Descripción:

Proyecto de investigación y análisis de datos orientado a evaluar el impacto de las métricas de red en el rendimiento escolar de estudiantes de ingeniería.

b. Requerimientos del cliente / proyecto:

  • Identificar la relación entre variables cuantitativas (Mbps, horas de uso) y cualitativas (satisfacción, estabilidad).
  • Diseñar una base de datos para la ingesta y estructuración de la información recolectada mediante encuestas digitales.

c. ¿Cómo se diseñó la solución?:

Se estructuró una base de datos relacional para procesar encuestas de Google Forms y exportarlas a herramientas de análisis como Excel y librerías de Python para cálculos estadísticos descriptivos.

d. ¿Cómo se implementó la solución?:

Se llevó a cabo un muestreo probabilístico aleatorio simple, se limpió el conjunto de datos y se aplicaron modelos de correlación para evaluar el rendimiento escolar frente al tiempo de pérdida por fallas de conexión.

e. ¿Cuál fue el resultado?:

Se generó un informe técnico detallado que identificó los principales cuellos de botella de conectividad y ofreció conclusiones claras sobre la infraestructura necesaria para sostener la productividad académica en la nube.
